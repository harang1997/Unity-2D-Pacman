# Unity 2D Pac-Man Game

## 프로젝트 소개
Pac-Man 스타일 2D 2D 플랫폼 게임 개인 프로젝트입니다.  
게임의 기본 로직인 몬스터 이동과 벽 충돌 처리를 구현하였으며, 플레이어가 점수를 얻고 적을 피하며 진행하는 형태로 설계했습니다.  

## 사용 기술
- Unity  
- C#  

## 담당 역할
- 모든 게임 로직 구현  
  - 몬스터 AI 및 이동  
  - 벽 충돌 처리  
  - 플레이어 캐릭터 이동 및 점수 시스템  
- 맵 구성 및 스프라이트 적용  

## 주요 기능
- 2D 게임 맵 구성  
- 몬스터 AI 및 이동  
- 플레이어 캐릭터 이동, 점프 및 점수 시스템  

## 프로젝트 형태
- 개인 프로젝트 (Personal Project)  

## 느낀 점
이번 프로젝트를 통해 Unity 환경에서 게임 로직을 설계하고 구현하는 경험을 쌓을 수 있었습니다.  
혼자 진행하면서 코드 구조 설계, 문제 해결, 기능 구현까지 직접 경험하여 개인 역량을 크게 향상시킬 수 있었습니다.
